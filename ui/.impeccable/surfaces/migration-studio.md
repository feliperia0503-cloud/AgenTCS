# Migration Studio

## THESIS

Una migración confiable se entiende como una ruta verificable: cada estación transforma código legado en conocimiento, evidencia y pruebas sin perder de vista el comportamiento original.

## OWN-WORLD

AgenTCS vive en una sala de trabajo empresarial sobria, diseñada para arquitectos y equipos de modernización. El azul noche sostiene la concentración, el fondo cálido evita la frialdad clínica, el teal identifica acciones reales y el ámbar sigue el recorrido de la migración. La navegación y los controles siguen convenciones web conocidas; el mundo aporta paleta, densidad, tipografía y una sola firma visual.

## STORY

El usuario entra, conecta el repositorio, obtiene una recomendación técnica, inicia la migración, inspecciona reglas con su evidencia y termina validando equivalencia funcional. Las decisiones irreversibles quedan bajo control humano y los datos ficticios se identifican como demostración.

## FIRST VIEWPORT

En escritorio y tablet deben leerse sin exploración previa: el proyecto activo, la etapa de migración, el repositorio fuente y las reglas prioritarias. La ruta Repositorio → Extracción → Validación → Generación → Pruebas funciona como estado global y nunca se reduce a puntos sin nombre. En móvil puede desplazarse horizontalmente, conservando nombres y estados.
